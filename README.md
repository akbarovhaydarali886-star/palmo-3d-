# palmo-3d-

Palmo Coconut Co. 1:1 3D Flavours Clone built with React, Three.js, GSAP, and Tailwind CSS.

## Features
- 🥥 3D Interactive Cans with Three.js (WebGL)
- 🌴 Custom GSAP Curtains & Liquid Fill Loader
- 🎨 Ellipse ClipPath Cart Drawer & Fullscreen Menu
- 🍍 Fruit Slicing Canvas Mini-Game
- ⚡ Fast Vite Build & Responsive Design
